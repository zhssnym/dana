### 7.3 Connections (roster)

- **GET /connections.** Response: `getConnectionsResponse` in
  `app/src/shared/connections.ts`. Excludes soft-deleted users. Sorted display_name
  ascending, then id. The element's email is non-nullable because of that exclusion: 8.10's
  scrub is the only thing that empties the column, and a scrubbed account is soft-deleted.
  Stating it in the shape makes a lost deleted_at filter a failure rather than a null.
- **DELETE /connections/:userId.** Either side may call. Deletes the pair row; both rosters
  lose the entry; existing memberships are untouched. 204; 404 if no such connection.

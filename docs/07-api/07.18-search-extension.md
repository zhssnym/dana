### 7.18 Search extension

GET /api/v1/search gains additive result kinds beside Q8's tasks: folders and shelves
(matched on name and description) and pages (matched on block text). Task matching extends
to step titles. The query contract and its limits are unchanged; a client that ignores the
new kinds sees exactly the v1 response. Query and wire shape: `searchQuery` and
`getSearchResponse` in `app/src/shared/views.ts`.

### 7.9 Reminder

- **PUT /tasks/:id/reminder.** Body `putTaskReminderBody` in `app/src/shared/tasks.ts`:
  offset_minutes when the task has a due_time, time_of_day when it does not; wrong mode 422;
  a task without due_date 422 (INV-6). Upserts the single row and computes fire_at (8.6);
  state resets to scheduled unless that instant is already past, in which case skipped,
  since a scheduled row with a past instant would be fired retroactively on the next tick,
  which 8.6 forbids. 200 with the affected TaskDetail, the reminder having no object or GET
  of its own.
- **DELETE /tasks/:id/reminder.** 204, idempotent.

### 8.11 Completion count

Per folder, identical for every member: completed = the folder's tasks in status
completed; pending = its tasks in status pending. Nothing is shown when both are zero;
otherwise the display is "completed / (pending + completed)". The counts reach the client
as `counts` on the folder (`app/src/server/domain/folders.ts`).

Abandoned rows count on neither side. Each completed occurrence of a recurring series adds
one to both sides over time; accepted as honest history. The sidebar badge shows the
pending number alone; the folder header shows the full ratio.

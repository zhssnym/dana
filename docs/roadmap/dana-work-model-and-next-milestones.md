# Dana Work Model and Next Milestones

## Milestone 1

1. **Add start dates to Tasks**

2. **BlockNote and Context foundation**
   - Smooth, targeted BlockNote implementation across Task, Folder, and Shelf.
   - Support H1–H3 headings, which form the default collapsible Section hierarchy.
   - Support file attachments, bulleted lists, numbered lists, checklists, media insertion (audio, video, and images), quotes, callouts, diagrams, and code blocks.

3. **Task relationships and dependencies**
   - Allow Tasks to reference other Tasks.
   - Display Dana links as modern UI chips for Tasks, Folders, and Shelves.
   - Support relationships such as **blocked by / blocking**.

4. **Tags / Labels**
   - Standardize Tags and Labels across the appropriate Work Units.
   - Include Tags and Labels in filters and Views.

5. **Responsibilities and Authorities**
   - Add Responsibilities for Folder members.
   - Add different Authority levels for members.

6. **Purpose**
   - Add the Folder-level **Purpose** facet with the Dana BlockNote composer and Dana Links capabilities.

7. **Consultation / Discussion**
   - Add or refine Folder-level Consultation.
   - Support Topics/Discussions, Comments, Replies, and Voting.
   - Allow Consultation to reference Purpose, Tasks, Sections, Results, and other Work items.

8. **Results / Outcome**
   - Add the Folder-level **Results / Outcome** facet with the Dana BlockNote composer and Dana Links capabilities.

9. **Core Folder facet strip**
   - **Main | Purpose | Consultation | Results | +**
   - Allow canonical facets to be hidden and unhidden.
   - For Milestone 1, **`+` should only allow blank composer facets and saved Views**.

10. **Task indicators**
    - Show finite Task progress on Folders and Sections, such as **17/22 done**.
    - Keep recurring Tasks separate, such as **17/22 done · ↻ 3 recurring** or **↻ 5/6 completed this week**.

## Milestone 2 and Later

1. **Precise Work Unit definitions**
   - Define Step, Task, Folder, Shelf, and Library precisely, especially for future AI use.
   - Decide whether an account can contain more than one Library.

2. **AI agents as team members**
   - Allow users to create AI agent personas.
   - Allow user-owned AI agents to become Folder members.
   - Apply the same Responsibility and Authority model to Human and AI members.

3. **History**
   - Make Work History accessible as a documentation/View surface, including through **`+`** where appropriate.
   - Preserve current state separately from historical state.

4. **Broader contextual AI**
   - AI chatbot.
   - Context-aware assistance.
   - MCP or similar external access.
   - AI support for Tasks, relationships, Consultation, Purpose, and Results.

5. **Milestones / advanced phasing**
   - Research whether Sections, dates, recurrence, and relationships already cover the need.
   - Add additional milestone/phasing concepts only where genuinely necessary.

6. **Expanded `+` extensibility**
   - Plugins.
   - Specialized facets.
   - Relationships, Evaluation, Timeline, Calendar, Assets, Risks, Budget, Compliance, Research, Specifications, Customer Information, and other domain-specific surfaces.

## Later structural iteration

After Milestone 2, Dana's structural areas should remain open to evidence-led reconsideration and iteration based on real use.

**Reusable workflows already exist in Dana.** They are not a future feature milestone. Existing workflows, workflow import, and other structural parts of Dana may be refined, revised, or reconsidered later when real usage shows a need.

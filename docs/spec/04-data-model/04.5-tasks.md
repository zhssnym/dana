### 4.5 tasks

| Column | Type | Null | Default | Constraint |
| - | - | - | - | - |
| id | uuid | no | generated | PK |
| folder_id | uuid | no | none | FK folders(id) ON DELETE CASCADE |
| title | text | no | none | length 1 to 300 |
| notes | text | yes | none | length up to 10000 |
| status | text | no | 'pending' | CHECK (status IN ('pending','completed','abandoned')) |
| important | boolean | no | false | none |
| start_date | date | yes | none | floating calendar date; when the task is intended to begin. CHECK (start_date IS NULL OR due_date IS NULL OR start_date <= due_date) (tasks_start_before_due_check); added by issue #215 on the 2026-09-20 ruling there, existing rows migrate null and nothing infers one |
| due_date | date | yes | none | floating calendar date |
| due_time | time | yes | none | minute precision; CHECK (due_time IS NULL OR due_date IS NOT NULL); v2 interfaces do not set it (RFC 0005); existing values are honored |
| recurrence_rule | text | yes | none | RRULE subset, section 4.11; CHECK (recurrence_rule IS NULL OR due_date IS NOT NULL); length up to 200 |
| series_id | uuid | yes | none | CHECK (recurrence_rule IS NULL OR series_id IS NOT NULL) (INV-13) |
| assignee_id | uuid | yes | none | see composite FK below |
| section_block_id | uuid | yes | none | FK page_blocks(id) ON DELETE SET NULL; the section this task sits under on its folder's page (4.17); null is the loose block |
| created_by | uuid | no | none | FK users(id) ON DELETE RESTRICT (users are soft-deleted) |
| completed_at | timestamptz | yes | none | CHECK ((status = 'completed') = (completed_at IS NOT NULL)) |
| completed_by | uuid | yes | none | FK users(id); CHECK ((status = 'completed') = (completed_by IS NOT NULL)) |
| deleted_at | timestamptz | yes | none | set marks Trash; purged by the 11.7 pass at 30 days |
| created_at | timestamptz | no | now() | none |
| updated_at | timestamptz | no | now() | touched on every mutation |
| position | text | yes | none | COLLATE "C"; the hand order of a folder's unscheduled list; null until that folder is first arranged by hand; gaps and ties allowed; ordered by (position, id) |
| page_position | text | yes | none | COLLATE "C"; the task's place in 4.17's mixed folder-page sequence; gaps and ties allowed; ordered by (page_position, id); nullable for rolling deploy compatibility |

Composite foreign key enforcing INV-4: FOREIGN KEY (folder_id, assignee_id) REFERENCES
folder_members (folder_id, user_id) ON DELETE SET NULL (assignee_id). The column-targeted
SET NULL form requires Postgres 15 or later; on older engines, drop the ON DELETE clause
and unassign inside the member-removal transaction instead (section 8.8 does so anyway;
the FK is belt and braces). This constraint also validates folder moves automatically:
changing folder_id with a stale assignee fails at the database.

Rationale lines: series_id groups a recurrence chain for guards (INV-7) and Done-page
trails; completed_by feeds the My Day recap (Q1R), makes the completion race guard natural
(section 8.5), and feeds the activity log of 4.13; updated_at is the last-write-wins
tiebreak evidence and the search recency key. Reads exclude rows with deleted_at set
except through the Trash surface of 7.13, the same guard 4.3 states for folders; a task in
a trashed folder is unreachable while its folder is, and purges with it.

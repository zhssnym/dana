### 4.7 my_day_entries

Columns and constraints: `app/db/migrations/0000_core_schema.sql`.

Its rows are **Today entries** (section 2); the table keeps its v1 name because a stored
identifier is not display copy. `added_on` is the adder's local date at pull time.

PK (task_id, user_id) is INV-12. The index on `user_id` serves Q1. Rows are additionally
deleted by the member-removal and leave transactions for tasks the user loses access to;
the task-deletion cascade covers the rest.

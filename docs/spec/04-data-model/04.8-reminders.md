### 4.8 reminders

Columns and constraints: `app/db/migrations/0000_core_schema.sql`.

- **One reminder per task**: `task_id` is the primary key.
- **Exactly one mode**: `offset_minutes` or `time_of_day`, never both (4.11). Which mode is
  legal depends on the task's `due_time` (an offset requires it, a time of day requires its
  absence); that is cross-table, so the API enforces it at every write.
- `fire_at` is computed (8.6). `fired_at` is set when `state` leaves `scheduled`. The
  partial index on `fire_at` where `state = 'scheduled'` serves the scheduler poll (Q11).
- A reminder cannot exist on a dateless task: the clear-date cascade (8.4) deletes it.

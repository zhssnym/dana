### 4.2 connections

Columns and constraints: `app/db/migrations/0000_core_schema.sql`.

`CHECK (user_a_id < user_b_id)`: canonical ordering makes INV-9 structural, so a pair is
one row whichever user created it. The index on `user_b_id` serves the reverse roster
lookup (Q9). Users are soft-deleted, so the CASCADE never fires in practice; the account
deletion transaction removes rows explicitly.

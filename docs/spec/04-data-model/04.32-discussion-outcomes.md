### 4.32 discussion_outcomes

One row is one **Outcome** of one Discussion (issue #320). Columns, constraints
and indexes: `app/db/migrations/0029_consultation_discussions.sql`.

Outcomes are **append-only**: nothing updates `statement`, and a changed
conclusion is reopen then resolve, which writes a new row and moves
`discussions.current_outcome_id`. Every earlier Outcome id keeps resolving to
exactly what it said. `statement` is 1 to 4000 characters after trimming, so
`Use as outcome` can snapshot any comment whole; `source_comment_id` records that
comment and is ON DELETE SET NULL, because the statement is a snapshot and never
follows the comment. `actor_id` is RESTRICT and outlives the account (8.10).

### 9.7 Settings

The page (`app/src/client/components/settings-page-content.tsx`) is one column at a form's
measure, centred in the space the shell gives it. Every row is a label with its control at
the far end, so the column has to be narrow or the two stop reading as one row, and a
narrow column flush against a wide page reads as a page that failed to fill.

Sections, each a named region:

- **Views** — the pin list: every view Dana has, native and saved alike, each with a pin
  switch. Desk is locked pinned, and says why: it is where a task goes when you have not
  said where, so it has to stay reachable. Done, Abandoned and Anytime ship unpinned.
- **Appearance** — theme (system, light, dark), row density, clock (12- or 24-hour), and
  where a task opens (dialog, panel, tab; 9.3). The theme is applied to the document before
  first paint from a copy mirrored into the browser, so a reload never flashes; 4.19's
  column stays the record, the mirror is written wherever the bundle is read or written,
  `system` mirrors as `system`, and sign-out clears it (`app/src/client/lib/theme.ts`).
- **Account** — the Google identity, shown as read from Google; profile picture upload
  (7.15), the picture itself being the control, drawn wherever the viewer is drawn, with
  "Remove" offered exactly while there is a picture; a timezone the viewer chooses, through
  7.1's PATCH /me, detected on the first session; storage used against 10.3's quota; and
  "Download my data", 7.22's export. The download is an anchor to GET /api/v1/me/export
  carrying the `download` attribute, not a fetch: a navigation carries the session cookie
  and hands 7.22's `Content-Disposition: attachment` to the browser, which saves the file
  under the server's name, where a fetch would parse the whole document into memory. The
  known cost is that the endpoint's rate-limit refusal arrives as a downloaded response
  rather than through 9.1's toast, since nothing in the client sees a navigation's status.
- **Sample data** — one row, drawn once the client knows whether 7.20's sample workspace is
  present, offering Remove or Restore. Remove confirms once with 9.1's dialog, then offers
  the undo bar, whose inverse is POST /sample. This row is the way back for a device that
  dismissed 9.13's strip.
- **Deleting your account** — the heading names the contents, not a feeling. Delete
  account shows its consequences, requires typing DELETE, and says that shared folders the
  viewer owns must first be handed to another member or deleted (Dana names which) and that
  private folders and their tasks are permanently deleted; this matches `DELETE /me`, which
  answers 409 naming every owned shared folder until each is transferred or deleted.

People is reached from the account menu (9.1), not from this page: one screen, one door.

### 9.14 Desk

Desk is the private, single-user Work surface. Its tab row starts with **Work**, then one
**Docs** documentation page, then a quiet `+`. Work is fixed first. The `+` adds another Doc
page only; documentation pages use the ordinary inline rename, reorder and Delete-to-Trash
treatment. Desk does not offer the usual-project picker, another Work tab or a Discussion
tab.

Discussion is collaborative and therefore absent from Desk. A Desk Task does not draw a
Discussion property, Start a discussion, a linked-discussion state, a count or an empty
Discussion state. Legacy Discussion data does not make a Discussion tab or Task property
appear. Shared projects keep their ordinary Discussion behaviour.

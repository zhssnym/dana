### 9.4 Today

Structure: the shared page head (the page's mark, title, editable description, and the
fact "N of M done"); then the Carried group (heading "Carried over"); the Today group
(heading "Today"); and the recap collapsed at bottom (heading "Done today (N)").

The important-only narrowing is the window bar filter's important switch; the page's
header carries no control of its own for it, because two controls for one variable forty
pixels apart is how the two disagree. `?state=important` (and any link that means "Today,
important only") seeds that filter rather than a page-local switch.

Row elements are the row's own (9.3), with this page's emphasis rules: a carried row keeps
its "Carried over" words and drops the red — a warning true of every row in the group
warns nobody; the pulled marker and its "Remove from My Day" un-pull control carry from v1
unchanged in behavior, the control reading "Remove from Today"; an unfiled task's folder
chip says Desk. Abandon-from-here copy carries: "Abandon this task? It stops appearing in
Today but stays everywhere else." Empty state per Q1. Error state: global toast plus
inline retry.

A task row opens that task, on every page that draws one and whatever the task's status —
the rule of v1's 9.4, unchanged, now through the surfaces of 9.3.

### 12.18 The application shell

The sidebar, the tab strip, the account menu, the confirmations, and the phone layout.
What a page draws inside the shell is 12.8 and 12.9.

- AC-155 Given folders with and without personal labels, then the sidebar pins Desk first with its pending count, groups the labeled folders by label ascending, and lists the unlabeled folders after them by name ascending.
- AC-162 Given each destructive action section 9 puts a confirm on, then the confirm carries that section's copy, offered as "Continue" and "Cancel", and declining it performs nothing.
- AC-171 Given a page whose read fails, then it renders 9.1's inline copy with the "Try again" control beside the thing that failed and the control refetches; given a read that answers 404, then it renders the not-found copy instead of the error state.
- AC-174 Given the application shell, then the sidebar is a navigation landmark carrying the app name, the global search control and the avatar menu, the app name links to My Day, and no chrome exists above or outside it.
- AC-175 Given the page entries and each folder row in the sidebar, then each is a link whose destination is that surface's path in 9.1's routes table, and the entry for the current page is marked as current.
- AC-182 Given the sidebar collapsed to its rail or resized, and given the task form resized, then each state survives a reload of the page, and the sidebar collapsed to its rail still reaches every page and every folder 9.1 puts in it.
- AC-183 Given each of section 9's normative strings that the designer's prototype omitted, split or reworded, then the built client renders each as one text run, character for character as its section writes it: 9.1's failed-read line and 404 line, 9.3's steps cap notice, 9.4's abandon confirm, 9.6's leave and remove-member confirms, 9.8's already-connected refusal and remove-connection confirm, and 9.1's member exit label.
- AC-214 Given the sidebar, then Today, Scheduled and Assignments are links in that order and no other native page is drawn, and the folder block is headed Library with Desk its first row.
- AC-215 Given /app/planned, then the browser lands on /app/scheduled; given /app/tasks, /app/all, /app/anytime, /app/important, /app/done or /app/abandoned, then it lands on /app/today, each replacing the history entry rather than adding one; given /app, then it lands on /app/today; and given /app/desk, then it lands on the default folder's page at /app/folders/<id> (spec 9.1).
- AC-216 Given a strip of two tabs, when the active one closes, then the neighbouring place shows; when the last one closes, then Today; tabs reorder by pointer drag; the strip's plus opens a folder as a new tab beside the current one.
- AC-242 Given the account menu, then it carries, in order, Settings, People, Trash, Import, Help and Sign out, which is 9.1's "Account"; each of the three places reaches its page when it is chosen and Import reaches a workflow file; and when Help is chosen, then a sheet of keyboard shortcuts opens naming the shortcut for search, and pressing that shortcut opens the search overlay.
- AC-264 Given the sidebar, then its footer carries the account row and nothing else — no "New folder", "New shelf", "Import", "Trash", "People" or "Settings" standing beside it — and the three acts of making are one "New" control on the Library's heading, resting visible, offering "New folder", "New shelf" and "New task", the first of which opens the dialog that makes one.
- AC-310 Given the application at a phone width (390 by 844), then a bar above the tab strip offers "Menu", "Search" and the bell; when Menu is pressed, then the sidebar opens as a drawer holding the page links; when a page link in it is pressed, then the page opens and the drawer closes; when Escape is pressed, then it closes; and when a task is opened, then its surface fits the phone's width with "Close task" on screen (spec 9.1, 9.3).
- AC-312 Given a page already open in a tab, when it is chosen from the sidebar or from "New tab", then that tab becomes active and no second tab is made; and given the strip holds only Today, then that tab draws no close control (spec 9.1).
- AC-401 Given the sidebar collapsed to its icon rail, then every glyph the rail draws shares one centre line, each centre-x agreeing with every other rather than with a fixed number (spec 9.1).

### 12.25 Desk

- AC-1540 Given a newly provisioned Desk, when its tabs or creation endpoints are used, then Work is its fixed root, Docs is its default Doc page, adding another Doc succeeds, adding Work, Discussion or the usual project is refused 422, and creating a Discussion directly or from a Desk Task is refused 409 (spec 7.30).
- AC-1541 Given an existing Desk with an untouched Purpose page, authored documentation and a legacy Discussion, when migration 0067 runs, then Work is first, Purpose becomes Docs without changing its page identity or content, any other Docs remain documentation, the legacy Discussion record is retained, and a Desk with no documentation receives one Docs page (spec 7.30).
- AC-1542 Given any Desk Task, when its task page is drawn, then no Discussion property, Start a discussion action, linked-discussion state, count or empty Discussion state is drawn; given a shared-project Task, its ordinary Discussion treatment is unchanged (spec 9.14).

### 12.17 First run and the sample workspace

What a brand-new account is given, and how a person removes it and gets it back.

- AC-226 Given an account holding no folder but Desk and no task, then Today offers the starter workflows beneath its list; when one is chosen, then its folder arrives with its tasks and with a page whose first block tells the person the example is theirs to delete, and the offer is not drawn again.
- AC-297 Given a brand-new account, when it signs in for the first time, then the sample workspace is present with the content module's own counts, and it reaches every feature it claims: shelves with labelled folders, page blocks with tasks under sections, steps, reminders, repeats, Today pulls, a folder conversation with a thread inside one task, completed rows (and nothing in Trash), and saved views (spec 7.1, 7.20, 4.21).
- AC-298 Given that account, when it signs in again, then nothing more is created; and given a development login carrying `sample: false`, then the account holds Desk and nothing else (spec 7.1, 7.20).
- AC-299 Given the account has made a folder and a task of its own, when it DELETEs /sample, then every registered object is gone with everything that hung on it, the person's own folder and tasks survive, the register is empty, and GET /sample answers absent; a second DELETE is 204 (spec 7.20).
- AC-300 Given a sample task with a thread the person moved into a folder of their own, when they DELETE /sample, then the task and its conversation survive where they put it (spec 7.20, 7.6).
- AC-301 Given a sample folder the person shared, when they DELETE /sample, then that folder and its tasks stand, the response names it in X-Dana-Sample-Kept, and the register is empty (spec 7.20).
- AC-302 Given the sample removed, when the person POSTs /sample, then it is present again with the same counts, and a second POST changes nothing (spec 7.20).
- AC-303 Given a brand-new account on Today, then the strip stands in the page's top bar (and on no other page) with the sample's folders in the sidebar and a link to Settings; when Settings' Remove is pressed, with no confirmation, then DELETE /api/v1/sample is on the wire, the strip and the sample folders are gone, the undo bar reads "Sample workspace removed", Settings offers "Add sample pages", and Today does not offer the starter workflows (spec 9.13, 9.7).
- AC-315 Given a brand-new account, then its Desk folder carries Dana's own sentence for that page in the description 4.3 gives every folder; and when the person rewrites it and then empties it, then their words replace Dana's and the emptied description stays empty (spec 4.3, 7.1, 7.4).

### 12.9 Pages, blocks and covers

The folder page as a document: its sections, paragraphs, images, board and cover. The
Library those pages hang under is 12.10.

- AC-058 Given a folder page, then it renders Scheduled, Unscheduled, and collapsed Completed sections and the 8.11 ratio.
- AC-176 Given a folder page, then its open tasks render in one region named "All open tasks" holding the folder's dated and undated open tasks together in Q7's order, a filter offers all open tasks, only those with a due date and only those without, and the Completed region stays collapsed with its control reporting that state.
- AC-197 Given a page-block write carrying a stale updated_at, then 409 with the 5.1 conflict copy; given a fresh one, then success and the last write stands for that block.
- AC-198 Given a page holding 500 blocks, when one more is added, then 422.
- AC-259 Given the board on a place page and the board on a folder page, then the columns are laid two to a row, so with three columns the third stands below the first rather than to the right of the second; and given a folder page, then it carries the view strip of 9.1 and choosing Board there draws that folder's tasks as the same board.
- AC-260 Given a folder page whose conversation is in the side panel, then the page's own body is narrower by about the panel's width than the same body with the panel closed, the panel taking room rather than covering it; and when the panel is closed again, then the body returns to the width it had.
- AC-270 Given a place page of 4.20's set, when the caller sets a cover as a preset, repositions it, and then replaces it with a stored file, then each write reads back as the caller's own entry and the last one wins; and given a second member setting a cover on the same place, then each reads their own and neither reads the other's; and given the file behind a cover deleted, then the cover is gone entirely rather than left as a row with neither a file nor a preset; and given a body naming both a file and a preset, or neither, then 422 naming the pair.
- AC-271 Given an image block on a folder's page, when a width of 25 to 100 is written through the page contract, then it reads back on that block and the page's other blocks are untouched; and given a width outside those bounds, or a width on a block that is not an image, then 422 naming the field and the page is exactly as it was.
- AC-293 Given a folder, when any member PATCHes `cover_preset` and `cover_focal_y`, then the Folder object answers both, a preset arriving clears a stored file and a file arriving clears the preset, a body naming both is 422, a crop outside 0 to 100 is 422, and the folder's duplicate carries the preset and the crop (spec 4.3 and 7.4 as amended by item 58, H; section 13 item 53).
- AC-295 Given a folder page in board view on its sections axis, then a Done column stands after the sections holding the folder's completed tasks and carrying an open card into it completes the task through 7.6's transition; and given the Done page, then its view strip offers Board and the board draws one column per completion day with every card finished (spec 9.1, 9.5, 9.6; ledger L-045 and L-049).
- AC-314 Given a signed-in person and the eight place pages of 4.22, when they read their place descriptions, then every place answers and each carries null where they have written nothing; when they write a sentence under one, then it reads back on the next read and nobody else's read carries it; when they clear it with null or with whitespace, then it reads null again so the client draws Dana's own sentence; and given a description past 500 characters, a body naming no description, an unknown place, or a caller with no session, then 422, 422, 404 and 401 (spec 4.22, 7.21, 9.4; issue #68).
- AC-335 Given a folder page, then the Section, Paragraph and Image tools at the foot are drawn at rest; when Section is pressed, the name field opens empty with "New section" as its placeholder; and a section's delete asks first, says where its tasks go, and offers "Keep it" and "Delete section" (spec 9.6, 4.17).
- AC-336 Given a shelf holding a folder, when its page is opened and opened again, then no "Someone else changed this block" toast is raised; a section pressed at the top lands there with its field open, empty and focused; and Escape while renaming the shelf puts the saved name back (spec 9.10, 4.17).
- AC-342 Given a folder wearing a cover, when the band is hovered, then "Remove" stands beside "Change" and takes the cover off in one act; and given the folder holds a finished task, when the board is shown, then its Done column is the one place that task appears (spec 9.6).
- AC-363 Given an image block on a folder page, then a member who did not upload the picture reads its width and height on the block, which is the whole of what the author already knew from the file they chose; given a block naming no file, and a block whose file was stored before migration 0009, then both are null and the client draws what it drew before the fields existed; and given the page written back unchanged, then the shape survives, the write shape having no field to carry it and therefore none to lose it with (spec 4.16 as amended, 4.17, 7.16; issue #27).
- AC-373 Given the three kinds of page a person can decorate, then each wears an uploaded picture and the picture's scope matches the page's: one folder-less file of the person's own dresses a shelf and a built-in place page and serves to them, while a folder's cover must be a file of that folder and is readable by every member, a private picture being refused as one (spec 4.3, 4.18, 4.20, 7.4, 7.15, 7.16, 7.19, migration 0012).

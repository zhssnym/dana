### 12.9 Pages, blocks and covers

The folder page as a document: its sections, blocks, media, board, cover and the reclaim of unworn pictures. The Library is 12.10; a document-bearing Folder facet's framework criteria (AC-837, AC-844) are 12.4's.

- AC-416 Given a folder page containing Sections, prose, images and real open tasks, when those items are inserted between named mixed neighbours and the page is fetched again, then `items` returns every item exactly once in the same order and the block and TaskCard payloads still name those identities; a paragraph inserted from a collapsed Section's after-span seam carries null `section_block_id` and remains in `No section` after refresh (spec 4.17, 7.16, 9.6).
- AC-418 Given persisted prose with current `updated_at`, when it is converted, then one real task replaces the paragraph at the same position and Section in one transaction; given stale evidence or content that cannot be a task title, then 409 or 422 respectively, the paragraph remains and no task is created (spec 7.16, 8.3).
- AC-419 Given a page action naming a Section, neighbour, block, file or item outside the folder, or a folder the caller cannot access, then it is refused as 422 or the indistinguishable 404 before any partial write, and every request field of the six action variants is read by the server (spec 7.16, 10.2, 10.3).
- AC-420 Given the folder canvas, when a person activates a seam or types `/`, then Task, Section and Image are offered without changing idle page rhythm; Ctrl/Command+Enter converts prose in place; Section collapse hides its stored members, and the collapsed Section's plus names `No section` and sends neighbours spanning all hidden children; YouTube/Vimeo render as frames while a direct mp4/webm/ogg URL remains an external link (spec 9.6).
- AC-422 Given a folder page with prose and adjacent task rows, then prose carries no adjacent plus, the task-to-task gap carries one structural plus quiet at rest and visible on hover or focus whose seam can create prose between the two tasks; an empty page or the true end of a populated one keeps exactly one `+ Do or write something…` continuation; and an outside press dismisses the structural menu (spec 9.6).
- AC-058 Given a folder page, then it renders Scheduled, Unscheduled, and collapsed Completed sections and the 8.11 ratio.
- AC-176 Given a folder page, then its open tasks render in one region named "All open tasks" holding dated and undated open tasks together in the folder's composed order, a filter offers all, only dated and only undated while preserving that order, and the Completed region stays collapsed with its control reporting that state.
- AC-197 Given a page-block write carrying a stale updated_at, then 409 with the 5.1 conflict copy; given a fresh one, then success and the last write stands for that block.
- AC-198 Given a page holding 500 blocks, when one more is added, then 422.
- AC-259 Given the board on a place page and on a folder page, then columns are laid two to a row, a third standing below the first; and given a folder page, then it carries 9.1's view strip and choosing Board draws that folder's tasks as the same board.
- AC-260 Given a folder page with its sharing panel open, then the page body is narrower by about the panel's width, the panel taking room rather than covering it, and closing the panel restores the width. - AC-271 Given an image block on a folder page, when a width of 25 to 100 is written, then it reads back on that block and other blocks are untouched; a width outside those bounds, or on a non-image block, is 422 naming the field with the page unchanged.
- AC-293 Given a folder, when any member PATCHes `cover_preset` and `cover_focal_y`, then the Folder object answers both, a preset clears a stored file and a file clears the preset, a body naming both is 422, a crop outside 0 to 100 is 422, and the folder's duplicate carries the preset and the crop (spec 4.3, 7.4).
- AC-295 Given a folder page in board view on its sections axis, then a Done column after the sections holds completed tasks and carrying an open card into it completes the task through 7.6 (spec 9.1, 9.6).
- AC-314 Given a signed-in person and the eight place pages of 4.22, then every place description reads null until written, a written sentence reads back for that person only, clearing with null or whitespace reads null again so the client draws Dana's own sentence, and a description past 500 characters, a body naming no description, an unknown place, or no session answer 422, 422, 404 and 401 (spec 4.22, 7.21, 9.4).
- AC-335 Given a folder page, then its "Insert into page" control at the foot is drawn at rest; choosing Section opens the name field empty with "New section" as placeholder; and deleting a section asks first, says where its tasks go, and offers "Keep it" and "Delete section" (spec 9.6, 4.17).
- AC-336 Given a shelf holding a folder, when its page is opened and opened again, then no "Someone else changed this block" toast is raised; a section pressed at the top lands there with its field open, empty and focused; and Escape while renaming the shelf restores the saved name (spec 9.10, 4.17).
- AC-342 Given a folder wearing a cover, when the band is hovered, then "Remove" stands beside "Change" and takes the cover off in one act; and a finished task appears on the board only in its Done column (spec 9.6).
- AC-363 Given an image block on a folder page, then any member reads the picture's width and height on the block; a block naming no file, or a file never measured, reads both null; and writing the page back unchanged keeps the shape (spec 4.16, 4.17, 7.16).
- AC-373 Given the three kinds of decoratable page, then each wears an uploaded picture scoped like the page: a folder-less file of the person's own dresses a shelf and a place page and serves to them, while a folder's cover must be a file of that folder readable by every member, a private picture being refused (spec 4.3, 4.18, 4.20, 7.4, 7.15, 7.16, 7.19).
- AC-374 Given a place page, when the caller names as cover a file that is not a picture they may wear (another person's avatar, or their own voice note), then 404 with one sentence for both and no cover row; a folder-less cover of their own or an image from a folder they belong to is 200 and reads back; and the same avatar as a shelf cover is 422, both endpoints admitting exactly readable files of kind cover or image (spec 4.16, 4.20, 7.15, 7.16, 7.19, 10.2).
- AC-375 Given a page block naming a file the page's own home cannot reach (another folder's file on a folder page, another person's folder-less picture on a shelf page), then 422 naming the field with the page unchanged, a uuid naming nothing answering the same sentence; and a file of the page's own folder, whoever uploaded it, or the shelf owner's own folder-less picture, is 200 and reads back (spec 4.17, 4.18, 7.15, 7.16, 10.2, 10.3).
- AC-413 Given an `image` stored with no `folder_id`, then 201, the row is the uploader's and readable only by them; a voice note with no folder is still 422; a shelf page's block may name that picture while a folder page refuses it 422 naming the field; setting it as that shelf's cover copies it into a new folder-less `cover` row the setter pays for; and once nothing references it, the 11.7 pass marks it, spares it while the mark is young and deletes it with its object after thirty days, while a picture a page still names carries no mark (spec 4.16, 4.17, 4.18, 7.15, 7.16, 7.19, 10.2, 11.7).
- AC-384 Given a page cover set from a picture living in a folder, then the page stores a copy the setter owns (no folder, kind cover), which still serves 200 after they leave the folder while the folder's picture is 404 to them; and two pages set separately from one folder picture each hold their own copy (spec 4.16, 4.18, 4.20, 7.15, 7.16, 7.19).
- AC-385 Given a cover file no page names any more, then the 11.7 pass leaves it while young and deletes the row and its object once past 30 days, the owner's quota falling by exactly its bytes; a cover still worn survives at any age; and clearing a cover is a replacement like any other (spec 4.16, 7.19, 10.3, 11.7).
- AC-386 Given one cover file named by two pages, then the reclaim spares it until the last reference goes, the other page drawing throughout; a file named only by a page block is spared too, references counting over every column that can hold a file id; and a cover file inside a folder is never considered (spec 4.16, 4.17, 4.20, 7.19, 11.7).
- AC-389 Given an account at 10.3's 1 GB, when a shelf cover, place cover, shelf duplicate or folder duplicate would copy a picture, then 413 `quota_exceeded` with section 9's sentence and no row, bytes or folder stored; and the same account setting a cover that copies nothing gets 200, the charge being for the copy (spec 7.15, 7.16, 7.19, 9, 10.3).
- AC-406 Given a shelf and a place page, when a picture is uploaded through the cover picker's Upload tab, then each page draws that served picture and still does after reload; dragging the place page's picture and saving stores the crop as a second write re-sending the cover, and the band is drawn there on next load; and choosing a gallery preset on the shelf afterwards removes the picture, the write reaching 7.16 (spec 4.18, 4.20, 7.15, 7.16, 7.19, 9.6, 9.10).
- AC-408 Given Desk and a person's own folder, when a picture is added through the insert control's Image item, then after reload the block draws it from 7.15's serving path and the browser reports it decoded, no "could not be stored" line shows, and the folder's cover picker stores a picture the band still draws on next read; and the same round trip completes on a shelf page (spec 4.17, 4.18, 7.15, 7.16, 9.6, 9.10, 10.8).
- AC-411 Given a folder page and a shelf page each holding an image block whose file 4.16 measured, then each reserves that picture's own proportion before the bytes arrive; and a block naming an unmeasured file draws as it did without the columns (spec 4.16, 4.17, 7.15, 7.16, 9.6, 9.10).
- AC-700 Given a folder-less picture a comment still carries through `comment_files`, when the 11.7 pass runs with its mark thirty-one days old, then row and object survive and the mark clears, while an identically aged unreferenced twin is deleted with its object and one aged twenty-nine days is kept; and once the attachment row is removed the next pass marks it afresh and the pass thirty-one days later deletes it (spec 4.16, 7.14, 7.15, 7.19, 11.7).

- AC-702 Given a folder-less picture a folder wears through `folders.cover_file_id`, when the pass runs with its mark thirty-one days old, then it survives and the mark clears, while an unreferenced twin is deleted and one aged twenty-nine days is kept; and once the cover is taken off the next pass marks it afresh and the pass thirty-one days later deletes it, leaving the folder wearing nothing (spec 4.3, 4.16, 7.4, 7.15, 7.19, 11.7).
- AC-703 Given a folder-less picture a shelf wears through `shelves.cover_file_id`, when the pass runs with its mark thirty-one days old, then it survives and the mark clears, while an unreferenced twin is deleted and one aged twenty-nine days is kept; and once the cover is cleared through `PATCH /shelves/:id` the next pass marks it from that moment and the pass thirty-one days later deletes it (spec 4.16, 4.18, 7.15, 7.16, 7.19, 11.7).

- AC-460 Given the folder canvas, when a document transaction writes a `bullet`, `numbered`, `checklist`, `quote`, `callout` or `code` block, then a later read answers each as its own kind with text and inline runs intact; `code` refuses rich content, none of the six carries a file, folder reference or width, and each refusal leaves the page's revision and blocks unchanged (spec 4.17, 7.16).

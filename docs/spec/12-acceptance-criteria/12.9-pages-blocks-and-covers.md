### 12.9 Pages, blocks and covers

The folder page as a document: its sections, paragraphs, images, board and cover. The
Library those pages hang under is 12.10.

- AC-416 Given a folder page containing Sections, prose, images, and real open tasks, when those items are inserted between named mixed neighbours and the page is fetched again, then `items` returns every item exactly once in the same order and the separate block and TaskCard payloads still name those identities; a paragraph inserted from a collapsed Section's after-span seam carries null `section_block_id` and remains in `No section` after refresh (4.17, 7.16, 9.6; issue #184).
- AC-418 Given persisted prose with current `updated_at`, when it is converted, then one real task replaces the paragraph at the same mixed position and Section in one transaction; given stale evidence or content that cannot be a task title, then the response is 409 or 422 respectively and the paragraph remains while no task is created (7.16, 8.3; issue #184).
- AC-419 Given a page action naming a Section, neighbour, block, file, or item outside the folder, or a folder the caller cannot access, when the action is attempted, then it is refused as 422 or the indistinguishable 404 before any partial write; every request field declared by the six action variants is read by the server and has a success or refusal assertion (7.16, 10.2, 10.3; issue #184).
- AC-420 Given the production folder canvas, when a person activates a seam or types `/`, then Task, Section, and Image are offered without changing idle page rhythm; Ctrl/Command+Enter converts prose in place, Section collapse hides its stored members, and the collapsed Section's plus names `No section` and sends neighbours spanning all hidden children; YouTube/Vimeo render as frames while a direct mp4/webm/ogg URL remains an external link (9.6; issues #177, #184).
- AC-422 Given a folder page containing prose and adjacent real task rows, then prose carries no adjacent plus, the exact task-to-task gap carries one structural plus that is quiet at rest and visible on hover or keyboard focus, and its full seam can create prose between those two task neighbours; given an empty page or the true end of a populated one, then exactly one visible `+ Do or write something…` continuation remains; and given its structural menu, then an outside press dismisses it (9.6; issue #192).

**AC-830 to AC-844 are the Folder facet framework (issue #210, M1-F, 2026-09-21).** Fifteen
invariants, one file each, named as the fifteen of Hassan's technical ruling,
https://github.com/zhssnym/dana/issues/210#issuecomment-5756722756, section 4. They live
here rather than split across 12.9 and 12.20 because a facet is a Folder concept before it is
a page or a Trash row: the framework decides identity, order, visibility and authority, and
the document and the Trash window are two of the things that framework then has. The registry
rule is one home per criterion, so 12.9's page bullets and 12.20's Trash bullets point here
rather than carrying copies.

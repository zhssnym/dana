### 12.10 Shelves and the Library

Shelves as rows and as pages, and the sidebar block that lists them. Moving a folder by
dragging is 12.19.

- AC-180 Given the sidebar's folder list, then a folder group can be created by naming it, renamed, and deleted, and a folder can be moved from one group to another or out of every group; and given a group deleted, then every folder that carried it and every task in those folders still exists, in the ungrouped list.
- AC-203 Given shelves, then (user_id, name) is unique; renaming keeps the shelf's id and its page; deleting clears the member labels and keeps every folder.
- AC-223 Given a shelf page, when a folder row is pressed, then the folder opens as its own tab beside the shelf's; when Add folder places an existing folder, then it joins the page without a reload.
- AC-257 Given a shelf created through 7.16, then the Library lists it after a full reload as a group headed by that shelf's name, that heading is a link to the shelf's own page, and the tab strip's "New tab" menu offers it beside the folders; and given a shelf no folder has yet been put on, then the Library lists it too, the block drawing the viewer's shelves rather than only the labels its folders happen to carry.
- AC-313 Given "New shelf", when a name is typed into "Shelf name" and "Create shelf" pressed with no folder ticked, then the shelf exists as a region of the Library named by it, empty, and the dialog says "shelf" and never "group" (spec 9.1, 7.16).
- AC-334 Given a person with shelves, when a folder page's "Move to shelf" is opened, then the submenu lists the shelves by name with "Not on a shelf" as the way off, choosing one moves the folder and the undo bar offers the way back, and the dialog calls the thing a shelf throughout (spec 9.1, 9.10, 7.16).
- AC-366 Given one person's shelf, when another person asks for it by id, then GET /shelves/:id, GET and PUT /shelves/:id/page, PATCH /shelves/:id and DELETE /shelves/:id all answer 404, never 403, and no refusal discloses the shelf's name (spec 4.18, 7.0, 7.16, 10.2).
- AC-367 Given a folder carrying a personal label, then that label names a shelf the viewer can open: a label written through 7.4 makes its shelf in the same transaction, migration 0011 gives a label stored before 7.16 the shelf it had none of, and clearing a label leaves the shelf standing (spec 4.4, 4.18, 7.4, 7.16, 9.1, 9.10).
- AC-368 Given a shelf, when its owner sets a cover through PATCH /shelves/:id, then the shelf wears it and a later read still has it; a file and a preset are one source, each arriving clearing the other; the crop stores and moves on its own; and clearing both leaves a shelf with no cover (spec 4.18, 7.16, migration 0012).
- AC-369 Given a shelf, when its owner names a cover they cannot reach, one that is not a picture, a uuid naming nothing, or a file and a preset at once, then 422 with one sentence for every unreachable case and the shelf unchanged; and given POST /shelves carrying a cover, then 422 rather than a silent 200 (spec 4.18, 7.16, 10.2, 11.14).

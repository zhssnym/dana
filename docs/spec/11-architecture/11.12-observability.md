### 11.12 Observability

- Sentry (free tier) receives server and client errors; AC-104 proves the wiring. - Better
  Stack (free tier): an uptime monitor on /api/health, and a heartbeat the scheduler pass
  pings after each successful cycle; heartbeat silence beyond 10 minutes alerts.
  /api/health also reports seconds since the last completed pass, and, since 2026-09-04
  and issue #80, `database`: which engine the seam of 11.5 chose, `"postgres"` or
  `"pglite"`, or null where nothing has declared one — a production process answering
  `"pglite"` is running on a database inside its own container and is the condition that
  section describes. The error tracker takes a message as well as an exception for the
  same reason: a condition worth alerting on is not always something that threw. - Dana's privacy-policy
  logger continues to write its structured application events to stdout, which leaves
  Render's deploy diagnostics and seven-day Hobby log explorer intact. When both
  `AXIOM_DATASET` and an ingest-only `AXIOM_TOKEN` are present, the same Pino records are
  also sent directly over HTTPS to that Axiom dataset, whose retention is at least 30
  days; with neither setting the external destination is disabled, and an incomplete pair
  records only the missing variable name and remains stdout-only. Only the closed,
  whitelisted logging surface of 10.5 reaches Axiom. Render platform and build logs are
  not copied and retain Render's own plan period. This direct destination is v1's accepted
  substitute for a Render workspace log stream because the free Axiom plan does not
  include its Secure Syslog endpoint and the free Better Stack Logs plan does not meet
  10.5's retention period.

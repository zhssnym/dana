## 13. Open questions, retired

**This section was retired on 2026-09-01 and holds nothing. It is a forwarding address.**

It had grown to 57 items, most of them long since decided, in a file nobody revisited. A
question parked in a document notifies no one, has no owner, and nothing marks it answered,
so it cannot be told apart at a glance from one that still matters. That is why open
questions are now GitHub issues, labelled `open-question` and assigned to whoever decides
them: `docs/workflow/how-we-work.md` carries the rule.

**Nothing is added here.** A new open question is an issue.

This table exists because 22 of these item numbers are cited from 56 files across the
repository, in source comments and in the specification itself. A citation of "section 13
item 16" still resolves, to the row below.

- **closed** means the thing it worried about was decided, shipped, or made moot. The text
  is in git.
- **a section number** means it was never a question but a recorded assumption, and it now
  sits in the section that states the behaviour it constrains, marked **Assumption:**.
- **an issue number** means it is genuinely open and someone owns it.

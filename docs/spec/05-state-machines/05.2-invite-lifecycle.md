### 5.2 Invite lifecycle

| Current | Event | Actor guard | State guard | Next | Side effects |
| - | - | - | - | - | - |
| (none) | create | any authenticated user | validations V-INV (section 8.7) | pending | one email sent; last_sent_at = now() |
| pending | accept | user whose lowercased Google email equals invites.email | acceptor not soft-deleted; the attached folder, when there is one, is not in Trash (409 `folder_deleted`, section 8.7) | accepted | acceptance transaction, section 8.7: connection upsert, membership grant if folder attached and absent, conditional assignment if task_id set; responded_at, accepted_by set |
| pending | decline | matched recipient (same rule as accept) | none | declined | responded_at set; no email to inviter |
| pending | cancel | inviter, or owner of the attached folder | none | canceled | responded_at set |
| pending | resend | inviter | now() minus last_sent_at at least 24 hours, else 429 | pending | email re-sent; last_sent_at updated |
| pending | inviter account deleted | system | none | invalidated | part of the account deletion transaction (section 8.10) |
| pending | folder purged | system | none | row removed | via FK cascade, at the 30-day purge of 8.8 rather than at the delete |
| any terminal | any event | any | never | rejected | 409 |

Terminal states: accepted, declined, canceled, invalidated. A new invite to the same email
and folder may be created after a terminal state; INV-11 only restricts pending
duplicates.

The accept row's second state guard was added on 2026-09-03 (issue #28). A folder's
deletion became soft when RFC 0005 was accepted, and the row below that carries the
purge, "folder purged | row removed | via FK cascade, at the 30-day purge of 8.8 rather
than at the delete", is what opened the window this guard closes: for thirty days the
invite is pending and the folder it names is in Trash, and nothing said which of those
two facts won. Refusal is what won, for 8.7's reasons, and the refusal is not terminal:
the invite stays pending, so a restore inside the window makes it acceptable again with
nothing else to repair.

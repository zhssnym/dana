### 10.5 Logging

Logged: authentication events, invite lifecycle transitions (invite id, not the email
address), folder deletion and account deletion with row counts, status transitions (task
id, actor id), reminder sends and skips, data exports (user id and byte count), request
errors with status codes. Never logged:
task titles, notes, step titles, email bodies, OAuth tokens, session identifiers.
Retention 30 days. No analytics or tracking in v1.

**The data export entry was added 2026-09-04 with 7.22 (issue #77).** The sentence above
is an enumeration rather than an illustration, so a new act that writes a log line is
added to it or it is not logged. Two fields and deliberately no third: who exported, and
how many bytes left. The size is the one thing worth knowing after the fact, being how
anyone would notice the endpoint outgrowing what building a document in memory can carry,
and it says nothing whatever about what was in it — which is what the "never logged" list
requires of a surface that touches every table a person's content lives in.

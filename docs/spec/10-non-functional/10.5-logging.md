### 10.5 Logging

Logged: authentication events, invite lifecycle transitions (invite id, not the email
address), folder deletion and account deletion with row counts, status transitions (task
id, actor id), reminder sends and skips, request errors with status codes. Never logged:
task titles, notes, step titles, email bodies, OAuth tokens, session identifiers.
Retention 30 days. No analytics or tracking in v1.

Added 2026-09-04 (issue #99): a Content-Security-Policy violation report reaching 10.8's
endpoint writes one warn-level `csp_violation` line carrying **three fields and no
fourth** — the effective directive, the blocked URI reduced to its scheme and host (or
the bare CSP keyword, `inline` and `eval` being the two that name Dana's own defects),
and the document's path with the query string removed. The exclusions are the point and
are why the whitelist is written here rather than left to the endpoint. A report carries
`script-sample`, which is a slice of the source that was refused and is therefore page
content, and its `document-uri` carries a query string, which on a search URL is whatever
someone typed; **neither may ever be logged**, and the logger has no parameter through
which either could arrive. A report from an origin that is not this deployment's, or one
this section's filters drop, writes nothing at all.

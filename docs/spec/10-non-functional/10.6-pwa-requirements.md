### 10.6 PWA requirements

Manifest: name Dana, display standalone, start_url /app, icons 192 and 512, theme and
background colors design's choice. Service worker: precaches the versioned application
shell (HTML, JS, CSS, fonts, icons); API requests are network-only, never cached;
navigations fall back to the cached shell so the installed app always opens. Updates: new
versions activate on next load; when detected mid-session, an unobtrusive "Update
available, reload" affordance appears; no forced reload. Install: rely on the browser's
native install affordance; Settings carries a short "Install Dana" hint section; no custom
install prompt interception in v1. Offline behavior is the ISSUE-19 contract: shell loads,
banner shows, reads need network, writes fail fast with the 9.1 toast. No IndexedDB
mirror, no background sync.

## 7. API surface

Every v1 page name here is an address, not a page name: `/views/my-day` serves Today,
`/views/planned` serves Scheduled, and keys such as `inbox` and `planned` keep their v1
spelling. The client and tests address these strings literally; section 9 names the pages.

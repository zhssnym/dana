### 7.12 Events and notifications

Query, lines and responses: `app/src/shared/events.ts`.

- **GET /events?folder=…** A folder's activity, newest first, member-only.
- **GET /events?subject=kind:id** One object's history, access via 10.2.
- **GET /notifications**, **POST /notifications/:id/read**, **POST
  /notifications/read-all.** The recipient's own list and read state.

Events are never written by clients; the chokepoint writes them.

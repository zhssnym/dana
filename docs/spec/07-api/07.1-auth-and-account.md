### 7.1 Auth and account

All 7.1 endpoints mount under the 7.0 base path: GET /auth/google is GET
/api/v1/auth/google, and likewise throughout.

- **GET /auth/google.** Unauthenticated. Takes an optional tz query parameter, an IANA
  identifier: the client's detected zone, carried to the callback through the
  pending-authorization state (11.6), never through redirect_uri and never composed into a
  redirect target. A value that fails the IANA validation guarding users.timezone is
  treated as absent rather than answered 422, deliberately unlike 7.0 and 10.3: sign-in must
  not fail over a stale zone database. Redirects to Google with scopes openid email
  profile.
- **GET /auth/google/callback.** Establishes the session. First login runs the provisioning
  transaction: insert the user (google_sub, lowercased email, display_name, avatar_url,
  timezone from the reported tz, UTC when none was reported), the default folder named
  "Inbox" with owner membership and Dana's own description sentence for that page (so the
  folder does not contradict the sidebar entry beside it; 7.4 edits it like any other), the
  user_settings row, and the 7.20 sample workspace unless the application was constructed
  with it off. The transaction is idempotent under the google_sub unique constraint: a
  concurrent duplicate loses and adopts the winner's rows. Every successful login syncs
  users.timezone to the reported tz when one was reported and it differs (8.1); a login
  carrying no tz syncs nothing. Sign-in is rejected with an explanatory page (copy in 9.2)
  if Google reports the email unverified. Redirects into the app, which immediately
  surfaces Q12 pending invites.
- **POST /auth/dev-login.** Present only under `DANA_DEV_LOGIN=1` and never in production
  builds. Its body takes an optional `sample` boolean that overrides the sample-workspace
  default for that account alone.
- **POST /auth/logout.** Destroys the session. 204.
- **GET /me.** Response: `meResponse` in `app/src/shared/me.ts`. `user.email` is nullable
  because 8.10's scrub empties the column and this endpoint excludes nothing; 7.3's roster
  email is non-nullable because that list excludes soft-deleted users.
- **PATCH /me.** Body: `patchMeBody` in `app/src/shared/me.ts`; 422 if the timezone is not
  IANA. Recomputes fire_at for scheduled reminders on tasks assigned to V (8.6). 200 with
  the GET /me object, so the client holds what a fresh GET would give it.
- **DELETE /me.** Body: `deleteMeBody` in `app/src/shared/me.ts`, the literal string
  "DELETE", else 422. Runs the account deletion transaction (8.10) and destroys all
  sessions. 204. INV-1, INV-2 and INV-10 survive via transfer-before-delete ordering.

Skipped wins, and this section takes the qualifier rather than 8.6 being amended. The grounds, verified through 8.6's loop rather than reasoned from the two sentences: the poll selects state = 'scheduled' and fire_at <= now() and skips only what is more than six hours stale, so a scheduled row with a past instant inside that window is delivered on the very next tick, which is exactly the retroactive fire the same section forbids. Reading the bullet literally therefore does not merely disagree with 8.6, it makes 8.6's own rule unreachable, which is what settles which of the two texts is wrong.

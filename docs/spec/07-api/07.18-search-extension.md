### 7.18 Search extension

GET /api/v1/search gains additive result kinds beside Q8's tasks: folders and shelves
(matched on name and description) and pages (matched on block text), each entry carrying
its kind, id, name, and route. Task matching extends to step titles. The query contract,
debounce expectations, the 2-to-100-character limit, and the 1000-row cap are unchanged; a
client that ignores the new kinds sees exactly the v1 response.

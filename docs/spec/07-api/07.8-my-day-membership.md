### 7.8 My Day membership

- **POST /tasks/:id/my-day?tz.** Inserts the entry (task, V, added_on = today(V)); repeat
  calls are 200 no-ops keeping the original added_on (INV-12). 404 if not accessible. tz is
  an IANA identifier and an absent or invalid one is 422 naming tz, as on view endpoints:
  today(V) is the date where the request says V is (8.1), and users.timezone is reserved for
  reminder fire instants.
- **DELETE /tasks/:id/my-day.** Removes V's entry; 200 even when absent (idempotent). Takes
  no tz, evaluating no date. The task remains in My Day when it still qualifies
  automatically.

Both answer the affected TaskDetail, since `pulled` is a field of the task and an entry has
no object of its own.

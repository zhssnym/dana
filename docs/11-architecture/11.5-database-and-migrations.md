### 11.5 Database and migrations

- Postgres 18 in production, and the same major everywhere tests run: PGlite embeds
  Postgres 18. Section 4's reference dialect (Postgres 16) remains valid; nothing in the
  schema requires more than Postgres 15.
- Drizzle ORM is the query client. The queries of section 6 are written as SQL through
  Drizzle's sql template so their ORDER BY clauses can be compared to the spec textually;
  CRUD may use the query builder.
- Migrations are hand-authored SQL files in `app/db/migrations/`, forward-only, with every
  constraint and index explicitly named (AC-001 asserts them by name). The Drizzle
  programmatic migrator applies pending migrations at server boot, before the health
  endpoint reports ready, and wraps each run in one transaction: all pending files commit
  or roll back together (11.15).
- Deploy interplay: the host's zero-downtime deploy keeps the old instance serving until
  the new one passes its health check. Postgres DDL is transactional, so a failed migration
  rolls back, boot fails, the deploy is canceled, and the old version keeps running.
  Destructive changes (drops, renames) must be split expand-and-contract across two
  releases, because the old code runs against the new schema during the overlap window.

**A production boot on the embedded engine announces itself and still starts.**
`app/db/client.ts` selects PGlite in `./.data` when it is handed no connection string, which
is what lets the suite run with no setup and is exactly wrong in production, where an unset
or empty `DATABASE_URL` puts the data inside a container whose filesystem may not survive a
spin-down. Such a boot writes one error-level `database_fallback_pglite` line saying what is
at stake, reports the same sentence through the error tracker of 11.12, and declares the
engine on `GET /api/health` as `database: "postgres" | "pglite"`. It does not refuse to
start, because refusing could take production down to prevent a data loss that instance may
not have; once `DATABASE_URL` is guaranteed, refusing becomes the right behaviour.

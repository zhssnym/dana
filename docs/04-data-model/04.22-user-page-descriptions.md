### 4.22 user_page_descriptions

One person's own sentence under one of Dana's place pages, private to them as
4.20's cover on the same page is. Columns and constraints:
`app/db/migrations/0008_place_descriptions.sql`.

- The `place` set is 4.20's. Desk is a folder and carries 4.3's own
  `description`, written at provisioning (7.1) and rewritten through 7.4 like
  any other folder's.
- **A row exists exactly when there are words**: `description` is non-empty, so
  clearing is the row's deletion and absence has one spelling. The 500 limit is
  4.3's and 4.18's.
- **Not a column on 4.20**, because that table admits no row without a cover and
  its file key cascades: a description would have nowhere to sit without a
  cover, and deleting a picture would silently destroy the sentence.
- No index: the primary key serves the only read, one viewer's descriptions.

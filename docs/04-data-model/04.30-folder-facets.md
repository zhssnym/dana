### 4.30 folder_facets

**Retired by migration 0061 (step 7).** A facet is a tab now: 0061 made every shown facet, and
every hidden one holding content, a page of its project (4.3) with the facet's id, moved its
`page_blocks` there, and made each private facet a Doc project whose only member is its owner.

migration drops them, so a bad deploy is fixed forward from data that still exists. R-CLEAN
(8.8) still deletes a leaver's private rows here, the ones 0061 left because their owner had
already left.

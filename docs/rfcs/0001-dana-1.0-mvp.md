# RFC 0001: Dana 1.0, the MVP

- **Status:** Draft
- **Created:** 2026-07-29
- **Target release:** 1.0.0

## Status of this document

Skeleton. This RFC is the one-time work order for building Dana's first release:
the motivation, the scope boundary, and the implementation plan that takes the
repository from empty to shipped.

Its source material is the build order currently held in `../specification.md`
(work packages P0 to P10, their dependency graph, and the mapping from packages to
the roles in `../team/`). That build order moves here, because it is a plan executed
once, while the specification keeps only what is permanently true about Dana.

The MVP is the single bootstrap case where the specification is written ahead of
the software rather than updated after a change lands.

## Sections to be written

- Summary and motivation: what Dana 1.0 is and the scope boundary that keeps it small.
- Implementation plan: packages P0 to P10, dependencies, owning personas, and the
  acceptance criteria ranges each package must satisfy.
- Alternatives considered: the design decisions argued down on the way here, which
  are preserved in this repository's git history.
- Open questions: the unresolved external facts the build must verify.

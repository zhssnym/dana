# dana pdd v1

**Main flow:** Talk about it → Turn it into a plan → Manage it as tasks  

**App structure:** Folder → Project/List → Task → Step

## Main idea

Dana is a normal to-do app with an AI chat built into it.

Users can:

- Create tasks manually
- Discuss a goal with Dana
- Turn the discussion into a structured plan

## Main sections

- My Day
- Important
- Planned
- All
- Completed
- Assigned to Me
- Tasks
- Calendar Imports
- AI Suggestions
- Dana Chat

## Two ways to create tasks

**Manual**

- Task name
- Project or list
- Steps
- Due date
- Reminder
- Repeat
- Importance
- Duration
- Assignee
- Notes

**With Dana**

- Discuss a goal or responsibility
- Create a project
- Break it into tasks and steps
- Suggest durations
- Suggest deadlines and reminders
- Review everything before saving

## Other useful features

Users can share:

- Screenshots
- Emails
- Messages
- Blackboard photos
- Meeting summaries
- Documents

Dana extracts possible tasks and lets the user add, edit, or ignore them.

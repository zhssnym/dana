A task is a unit of work with an owner and, if you want, a schedule. Dates are optional: a task can have a **Start Date**, a **Due Date**, both, or neither.

## Make and finish tasks

Add a task with the task control in a Work Facet, or press **N** when you are not typing. Open a task to add notes, assignees, and dates. Mark it complete with the control beside it, and reopen it if the work is not done. Right-click a task for more actions, such as copying its link.

## What the dates mean

The Start Date is when the work should begin. The Due Date is when it should be finished. Dana activates a task on its Start Date, or on its Due Date when it has no Start Date. In the Calendar view, drag either end of a date range to change it.

## Today, Upcoming, and Assigned

These lists collect tasks from all your pages, so you do not have to open each page.

- **Today** shows work that is active now. You can also pull any task into Today yourself.
- **Upcoming** shows every task with a Start Date or a Due Date.
- **Assigned** shows tasks and who is responsible for them.

Other lists can show overdue work and tasks with no date. Your sidebar settings control which lists you see.

## A task is missing from Today

It is probably scheduled for later, or it is already complete. Check its dates, or pull it into Today.

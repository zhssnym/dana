A view changes how Dana presents your work. It does not create a second copy of the tasks.

## Available views

- **Thread** presents work in an ordered sequence.
- **Freeform** presents work as a continuous working document.
- **Board** groups tasks into columns.
- **Calendar** places scheduled tasks on dates.

Choose the view that suits the work you are doing. Changes to a task are reflected across views.

## Set a preferred view

Open **Settings** and find **Default Work view** under Preferences. Choose Thread, Freeform, Board, or Calendar.

For scheduling details, see [Schedule a task](/help/schedule-a-task).

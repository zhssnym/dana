Every Work and Doc Facet is also a place to write. Keep the context, notes, and decisions next to the tasks they explain.

## Blocks

Type **/** to add a block: headings in three sizes, lists, checklists, quotes, code, tables, files, and a Teammate block that shows a person's current profile. In a Work Facet, headings also make the sections that group your tasks.

## Backlinks

**Referenced from**, at the bottom of a Work or Doc page, lists the pages that link to it. It also lists pages that hold a synced copy of one of its blocks.

## Synced blocks

A synced block shows the same content on many pages. Select **Copy and sync** in a block's menu, then paste the link on another Work or Doc page. An edit in any copy changes the original, and all copies show it. While you edit, the block shows a frame and **Synced to N other pages**.

To make a copy normal text again, select **Unsync**. If the original is deleted, each copy keeps its last content as a normal block.

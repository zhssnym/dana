Tasks record work that needs to be done. A task can have a title, writing, assignees, and an optional schedule.

## Create a task

1. Open a Work area.
2. Choose the visible task-creation control, or use **Task** from the writing menu where it is available.
3. Enter a clear task title.
4. Add details or a schedule if the task needs them.

You can also use **N** in a supported task list when you are not typing in a text field.

## Mark a task complete

Use the completion control beside a task. You can reopen it if the work is not finished.

## Open a task

Select a task to see its details. Depending on the view, you can also right-click a task for actions such as copying its link or opening it in a new tab.

[Schedule a task](/help/schedule-a-task) explains Start Date and Due Date.

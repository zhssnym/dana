A page is the home of one piece of work. Its writing and its tasks live together, so the context, notes, and decisions stay next to the work they explain. A page shows its content in **Facets**, the tabs at the top: a Work Facet for tasks and progress, a Doc Facet for notes.

## Writing

Type **/** to add a block: headings in three sizes, lists, checklists, quotes, code, tables, files, and a Teammate block that shows a person's current profile. In a Work Facet, headings also make the sections that group your tasks. A checklist is only text. Use a task when the work must be assigned, scheduled, or completed.

## Tasks

A task is work that someone can finish. Add one with the task control in a Work Facet, or press **N** when you are not typing. Open a task to add notes, assignees, and dates. Mark it complete with the control beside it, and reopen it if the work is not done. Right-click a task for more actions, such as copying its link.

## Dates

Dates are optional: a task can have a **Start Date**, a **Due Date**, both, or neither. The Start Date is when the work should begin, and the Due Date is when it should be finished. Dana activates a task on its Start Date, or on its Due Date when it has no Start Date. In the Calendar view, drag either end of a date range to change it.

## Today, Upcoming, and Assigned

These lists collect tasks from all your pages, so you do not have to open each page.

- **Today** shows work that is active now. You can also pull any task into Today yourself.
- **Upcoming** shows every task with a Start Date or a Due Date.
- **Assigned** shows tasks and who is responsible for them.

Other lists can show overdue work and tasks with no date. Your sidebar settings control which lists you see. If a task is missing from Today, it is probably scheduled for later or already complete.

## Backlinks

**Referenced from**, at the bottom of a Work or Doc page, lists the pages that link to it. It also lists pages that hold a synced copy of one of its blocks.

## Synced blocks

A synced block shows the same content on many pages. Select **Copy and sync** in a block's menu, then paste the link on another Work or Doc page. An edit in any copy changes the original, and all copies show it. While you edit, the block shows a frame and **Synced to N other pages**. To make a copy normal text again, select **Unsync**. If the original is deleted, each copy keeps its last content as a normal block.

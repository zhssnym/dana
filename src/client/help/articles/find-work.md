Dana offers several ways to return to your work.

## Library

Use the sidebar Library to move between pages and organized work areas. Pages can contain nested pages.

## Focus lists

Use **Today**, **Upcoming**, and **Assigned** to see tasks across different pages without opening each one.

## Search

Select the sidebar Search control, or press **Ctrl+K** on Windows/Linux or **⌘K** on Mac. Search can find tasks and pages you can access.

## Breadcrumbs

Breadcrumbs in the top bar show where you are. Select a linked segment to move back to its parent location.

For the full keyboard reference, see [Keyboard shortcuts](/help/keyboard-shortcuts).

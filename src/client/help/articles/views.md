A view changes how Dana shows your work. It does not copy the tasks, so a change in one view shows in all of them.

- **Thread** shows work as an ordered sequence.
- **Freeform** shows work as one continuous document.
- **Board** groups tasks into columns.
- **Calendar** puts scheduled tasks on their dates.

Switch views from the view control at the top of a Work Facet. To pick the view that opens by default, go to **Settings** and set **Default Work view**.

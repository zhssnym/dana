Dana pages are also writing surfaces. You can keep explanations, notes, and supporting material beside the work.

## Insert content

1. Open a page and place the cursor where you want to write.
2. Type text normally.
3. Use the **/** menu to insert a supported block.

The menu includes headings and common writing blocks such as lists, checklists, quotations, code, and supported media.

## Use headings

Headings make long pages easier to scan. In Work, some headings also define the sections used to organize tasks. Use a heading to describe a meaningful part of the work, not only for decoration.

## Keep content close to its purpose

Use writing for context and instructions; use a Task when you need an item that can be assigned, scheduled, and completed. A checklist in a document is not always the same as a Dana Task.

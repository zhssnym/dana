Dana provides two different ways to communicate.

## Discussions

Use a **Discussion** when the conversation belongs to shared work. A Discussion can connect to tasks so teammates can understand the context and outcome.

Discussions can be open or resolved. They are part of the shared work area's conversation history.

## Direct messages

Use **Direct Messages** for a private text conversation between two people. A direct message does not become a Discussion on a shared page.

You can start a message from a teammate's profile or the Messages control when available.

For details about who can access a shared area, see [Collaborate on work](/help/collaborate-on-work).

### The AC-162 ruling, since it was asked for

**The control 9.5 names on a Done row is the task row's completion checkbox, and
AC-162 addresses it as one.** Four sentences of the re-accepted text agree and
none of them is the criterion:

- 9.1's names table: `A task row's completion checkbox, and the task form's
  completion control (9.3, 9.4) | "Complete task" when open, "Mark as not done"
  when complete`.
- 9.1's paragraph beneath it: the two are "one control pointed at one object
  from two places".
- 9.4's row elements: "complete checkbox".
- 9.3 as RFC 0002 rewrites it: the form's completion control "is the same
  transition 9.4's row checkbox and 9.5's 'Mark as not done' make, and takes
  9.5's confirmation unchanged on the G-SERIES successor branch".

`pages/DonePage.tsx`'s own header states the objection plainly and it deserves
an answer rather than a verdict: 9.5 gives this page a control that confirms
before it acts, and "a checkbox that sometimes opens a dialog would be that
behaviour hidden inside the one control every other page uses unconditionally".
That is a real product argument and it is not a reading of the specification.
The fourth sentence above disposes of it: 9.3's completion control confirms on
exactly that branch, and AC-179's third case asserts it doing so, so confirming
is a property of the transition rather than of a role. What is left is two roles
answering to one name in one table, which 9.1's addressing sentence does not
admit, and a leg that already reaches this same control as a checkbox in AC-157
and in `session-path`.

**The repair is one edit in `pages/DonePage.tsx`:** drop the composed row for
`components/task-row.tsx`, whose completed row already carries this name on a
checkbox, keeping the G-SERIES confirm on the un-complete path. Owner: role 07,
whose `pages/` this is. If the Steward rules the other way, 9.5 should say so
beside 9.1's table and this case takes `button` back; it is one string in one
file either way. **No row in this run is scheduled on `pages/DonePage.tsx`**,
which is why the red is named here rather than left to be found.

checkbox the completion control that criterion counts. It is a native

test and to a person and is not a checkbox to a role query.

this surface has over that one.
